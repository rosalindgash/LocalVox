# Roadmap

## v0.1 — It talks
- Named persistent voice profiles
- Reference audio copied into managed storage
- Explicit voice-consent confirmation during enrollment
- Script editor
- Engine abstraction
- OpenVoice V2 worker adapter
- Background generation so the UI remains responsive
- WAV output
- CPU-first Windows behavior
- Automated tests on Windows

## v0.2 — It becomes useful
- Projects
- Long-form sentence/paragraph chunking
- Segment-level regeneration
- Audio joining and loudness normalization
- MP3 export

## v0.3 — It becomes pleasant
- In-app recording and trimming
- Voice presets
- Generation history
- One-click runtime setup
- Windows installer

## v0.4 — It gets fast
- DirectML-compatible engine option
- GPU detection and safe fallback

## v1.0
- Stable installer
- Accessibility pass
- Documentation and tests
- Signed releases where feasible
